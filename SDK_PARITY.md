# SurrealDB.js capability audit

This audit compares the Kotlin driver's public capabilities with every distinct name exported by the official JavaScript SDK. It measures what a Kotlin user can do, not whether both SDKs use the same names or runtime design.

## Snapshot and method

- Audit date: 2026-08-22.
- Upstream repository: [`surrealdb/surrealdb.js`](https://github.com/surrealdb/surrealdb.js).
- Pinned commit: [`7939ed8eb9d77536f7ff3d5018155a0f18008548`](https://github.com/surrealdb/surrealdb.js/tree/7939ed8eb9d77536f7ff3d5018155a0f18008548). The audit resolved `main` once and kept this commit even if the branch moved later.
- SDK package: [`surrealdb` 2.0.8](https://github.com/surrealdb/surrealdb.js/blob/7939ed8eb9d77536f7ff3d5018155a0f18008548/packages/sdk/package.json).
- Public entry points: the package export map exposes only `surrealdb` at `.`. Its [root barrel](https://github.com/surrealdb/surrealdb.js/blob/7939ed8eb9d77536f7ff3d5018155a0f18008548/packages/sdk/src/index.ts) re-exports `@surrealdb/sqon`, so those names are part of the SDK root entry point and are included below. The conditional Node bundle re-exports the same public names.
- Enumeration: the TypeScript compiler resolved the root module's export graph, including type-only exports and aliases. Merged type/value declarations such as `ErrorKind` count once because consumers import one distinct name.

The snapshot contains **233 distinct exports**: **133 Present**, **57 Missing, wanted**, and **43 Deliberately absent**. This branch implements none of the missing capabilities.
